# Control center and settings continuation

`lumina-shell-26.9-2.lu26` replaces the generic quick-settings drawer with an
ii-derived control center and a separate settings window. The eighteen newly
imported Material widgets and adapted layouts are listed in `lumina-shell/UPSTREAM.json`.

## Working surfaces

- Grouped control-center tiles, volume/microphone/backlight sliders, connection
  and power state, DND, light/dark mode, notifications and a compact calendar.
- A settings navigation rail with Quick, General, Bar, Background, Interface,
  Services, Advanced and About pages. The rail scrolls on short displays.
- Wallpaper file selection and Cassiopeia reset; shell theme, transparency,
  reduced motion and interface font; bar labels, assistant/tray visibility and
  clock format; notification duration, DND and control-center preferences.
- Preferences apply immediately and survive a new shell process. The save
  debounce coalesces rapid changes, and switches follow external model updates.
- Device details launch the packaged Fedora managers. Missing Bluetooth/audio
  devices are disabled, missing backlights are hidden, and failed helper actions
  display errors. Brightness writes retain the latest requested value.

## Verification

The matching native Fedora 44 ARM64 runtime passed the real Chroma/Quickshell
integration suite at 1280x800, plus two 1920x1200 outputs at 200% scaling.
All eight settings pages loaded. The fixture exercised the actual preference
switch handler, model synchronization, light palette, opaque content cards,
save coalescing, and preference restoration in a fresh process. Existing
Chroma zoom/window-close and QML assistant/HTTP tests passed. Fifteen Python
assistant/control tests passed, including unavailable hardware, network names
with colons, action rejection and failure reporting.

Host-wide unittest discovery initially invoked the standalone QML script
against the host's incompatible Quickshell/Qt private ABI. The QML script was
then run successfully in the matching native container; host runtime execution
is not claimed. The integration run's system D-Bus/UPower/Bluetooth warnings
reflect the isolated container and do not qualify physical hardware.

The x64 installed VM runs this source from
`/home/luminaqa/lumina-shell-parity/shell`. Through noVNC, the control center
opened, DND changed and saved, settings opened from its gear button, and light
and dark mode changed both settings and the bar. The VM reports its Ethernet
connection and balanced power profile; absent audio/Bluetooth controls remain
disabled. This development preview does not alter the installed RPM payloads.
Its observed GUI state is separate from the earlier signed-image acceptance.

Raw logs/screenshots are retained under `desktop/evidence/parity-20260912/`.
The compact record and RPM/SRPM digests are in
[`evidence/cassiopeia-shell-parity-20260912.json`](evidence/cassiopeia-shell-parity-20260912.json).
The source bundle and both unsigned development RPM artifacts build successfully.
