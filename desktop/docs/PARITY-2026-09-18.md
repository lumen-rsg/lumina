# Sidebar widgets and media continuation

`lumina-shell-26.9-3.lu26` adapts the pinned end-4 ii lower sidebar and media
controls to the existing Lumina shell. The source revision remains
`97c5bc651f68092351b24aaa935af708b1e04514`; adapted layouts are recorded in
`lumina-shell/UPSTREAM.json`. Chroma's bundled shell is not used.

## Implemented

- Collapsible Calendar / To Do / Timer group with the upstream navigation rail.
  The compact row exposes all three tabs; expansion scrolls to the group on
  small displays. The clock opens its expanded calendar view.
- To-do and done lists, completion/reopening, delete and undo, literal task text.
- Pomodoro focus, short breaks and a long break every fourth focus session;
  Start/Pause/Reset and configurable durations in Settings → Services.
- Stopwatch Start/Pause/Reset, elapsed time and lap recording.
- Tasks, countdown deadlines, stopwatch and laps survive sidebar closure and
  fresh shell processes. State is stored in `~/.config/lumina/productivity.json`
  (or the configured XDG location). Invalid saved state is preserved and edits
  disabled with a visible error. Focus transitions notify locally and pause
  before the next phase, including recovery after a restart or suspend.
- MPRIS media card with artwork, title/artist, player selection, play/pause,
  previous/next and a wavy seek bar. Capability changes and player removal
  disable unavailable controls. Settings can hide the card and widget group.

## Verified

The matching Fedora 44 ARM64 runtime, Quickshell `2d3b3e9` and the existing
Chroma QA binary passed `desktop/tests/smoke-shell.sh` at 1280×800 and on two
1920×1200 outputs at 200% scaling. The gate rejects QML errors and binding loops.
An imported scrollbar's implicit-size loop was fixed during this work.
A short-display fixture clicks the compact Timer tab and verifies that the
expanded timer buttons lie inside the scrolled viewport. This caught and
fixed a scroll request issued before layout finished.

The real QML task/timer fixture exercises the Add and Start controls, task
completion/delete/undo, seven focus/break transitions, exactly-once completion,
stopwatch lap/pause, fresh-process reload, and invalid-file preservation.
A separate session-bus MPRIS player receives Play, Pause, Next, SetPosition to
90 seconds, Previous and Quit from the rendered card. The fixture verifies
metadata/capability updates and removal of the player. This tests the actual
Quickshell D-Bus integration, not a substituted media service.

Existing eight-page settings/persistence and Chroma zoom/close tests pass.
The four Python control tests, eleven assistant tests and QML assistant HTTP
round trip pass. The host sandbox cannot bind a loopback test server, so the
assistant HTTP tests ran in the matching QA container. Python GObject was
installed only in that container for the MPRIS fixture. The container was
returned to its original stopped state after testing.

Both unsigned noarch RPM and SRPM build successfully. Offline source accounting
passes for all ten packages. Compact evidence and artifact hashes are in
[evidence/cassiopeia-shell-parity-20260918.json](evidence/cassiopeia-shell-parity-20260918.json).
Raw fixture logs and screenshots are under `desktop/evidence/parity-20260918/`.

## Boundaries

This is native ARM64 development verification. The updated shell has not yet
been exercised in the x86-64 installed VM, signed/published by LuminaCI, or
composed into new installer images. Existing `b1feea2` images retain release 1.
The isolated runtime lacks system Bluetooth/UPower and DRM/Xwayland; these tests
do not qualify physical hardware or X11 applications.

The dock, embedded network/pairing/audio dialogs, persistent notifications,
night light, tile editing, dynamic Material colors, calendar events, media
visualization/lyrics and the other modules in `PORT.md` remain open.
